# 小米体重验证（独立实验工具）

此 Android 工具用于检查当前账号能否通过非官方通路读取近 7 天的体重原始记录，版本为 `0.1.0-probe01`，最低支持 Android 9。

包名为 `com.personal.fitnessledger.xiaomiprobe`，与正式账本 `com.personal.fitnessledger` 分开安装，不覆盖账本，也不向账本数据库写入记录。它不是正式版功能、后台自动同步服务或小米官方应用。

## 使用方法

1. 安装主任务交付的独立验证 APK，打开“小米体重验证”。
2. 首次连接前阅读并主动勾选告知：这是非官方账号会话通路；获得的会话权限可能超过本次体重读取范围，并非小米官方的限权 OAuth 授权。本工具实际只发起当前账号的体重读取。
3. 点击连接，再点“在小米页面登录”，由你本人在系统浏览器打开的小米官方登录页面操作。密码、验证码、扫码确认均由你本人完成，不交给工具或助手。登录链接过期后需重新连接。
4. 回到工具，看到“登录已确认”后点击“读取近7天记录”。查询使用中国大陆健康服务地址；其他数据区域、账号或设备可能无法返回数据。
5. 将返回的测量时间、体重、体脂率、含水率逐条与小米报告核对，确认确实属于你。完成后点击“断开并清除”。

若没有可展示记录，不能据此判断你的小米报告为空，也不能据此判断设备损坏或不受支持。可先检查账号、云端同步与近 7 天是否有记录。

## 数据与会话边界

- 仅显示服务返回的原始 `weight`、`body_fat_rate`、`moisture_rate`。体脂率、含水率缺失或为零时留空，不依据体重、BMI、账号资料推算，也不补造记录。
- 时间按接口秒级时间戳处理，重量按已研究接口的千克语义处理；不按数字大小猜测毫秒或磅。异常时间、数值、明确不支持的单位及冲突修订会排除并提示。相同时间和来源的重复记录合并；同一天不同时间的测量保留。
- 查询按天限制范围；分页上限、异常行或未完成的读取意味着结果可能不完整，不能当作完整历史。来源标识不能证明具体设备型号、测量成员或记录归属。
- 凭据和结果仅由本工具进程内存持有，不写入文件、偏好设置或账本。按返回键离开工具、断开/取消、页面重建或进程结束都会丢弃本工具持有的会话与结果；再次读取需要重新连接。
- 临时切换到浏览器或桌面不等于按返回键退出；这是为了完成官方页面登录。需要立即清除时，请使用工具中的断开/取消。
- 本工具不会注销浏览器自身的小米登录状态，也不能保证撤销服务端账号会话。如需退出浏览器账号，请在小米官方页面自行操作。
- 2026-09-21 用户已完成真机登录并报告“读到了。没有问题”。这确认了该账号的前台读取可用，不等于所有指标始终返回、完整历史已核对、后台自动同步可靠或获得小米认证。
