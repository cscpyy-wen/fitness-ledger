# GLM-5.3-Flash 兼容修复

2026-09-22，alpha09 / versionCode 26；数据库 v11。

## 使用方式

覆盖安装新版后，已保存的GLM连接和附加提示词无需重建。在“方案 → 设置 → 整餐AI识别”编辑所需连接：

- Base URL：`https://open.bigmodel.cn/api/paas/v4`
- 模型ID：`glm-5.3-flash`
- Key：只在手机中填写本人智谱开放平台Key。此前发到聊天中的Key应在控制台撤销后换新。

地址不变时可直接更新Key；升级本身不会调用模型。回到饮食页选择该服务，主动拍照或重试后才发送请求。默认GLM预置仍为 `glm-4.6v`，不擅自改变用户选择或计费模型。

## 原因与改动

alpha08根据智谱域名统一发送 `thinking:{type:"disabled"}`。该参数适用于原预置GLM-4.6V，但GLM-5.3-Flash拒绝关闭思考，返回HTTP400、智谱错误1210。

alpha09按模型区分：官方GLM-5.3-Flash使用 `reasoning_effort:"low"`，不发送关闭开关；原GLM-4.6V保留原设置；未知模型不擅自附加思考开关。仅规范官方GLM-5.3-Flash模型名的大小写，不改自定义域名的模型ID或参数。

对GLM-5.3-Flash修正后的请求加入新的稳定重试命名空间，避免与旧参数的失败请求复用标识。每次用户明确操作仍只发送一次，不自动重试或切换服务；仍可能由供应商按请求计费。

HTTP400现在明确为请求参数被拒绝。对官方智谱1210，仅分类成“不能关闭思考”或“参数不接受”的本地固定说明；任意供应商错误原文不进入异常、日志或界面，避免回显密钥、照片或附加资料。

## 证据与边界

此前诊断做了两次最小官方文本请求：旧关闭参数返回400/1210；去掉关闭参数并使用low档后返回200、正常结束和OK文本（20 tokens）。这仅证明当时的文本接口参数及账号可用，不证明照片估算准确率或整餐延迟。本轮修复不再使用此前暴露的Key，回归使用合成响应和测试密钥。

新增回归覆盖照片及附加说明仍发送、模型名规范、低思考参数、旧模型与自定义域名隔离、重试标识、错误原文不回显以及仍须确认入账。实际签名包和自动化/升级结果以顶层交付报告为准。

官方资料：[GLM-5.3-Flash多模态能力](https://autoclaw.z.ai/blog/model/glm-5.3-flash/)、[官方模型连接与思考参数说明](https://zcode.z.ai/cn/docs/configuration)。后者区分通用API和Coding端点；本App属于饮食识别，不将Coding套餐端点作为替代。
