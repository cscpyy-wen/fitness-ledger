# 0.6.0-alpha11 发布说明

## 安装

在 [GitHub Release](https://github.com/cscpyy-wen/fitness-ledger/releases/tag/v0.6.0-alpha11) 的 Assets 中下载 `fitness-ledger-0.6.0-alpha11.apk`。这是与本地交付完全相同的 APK，只改了下载文件名。

旧版用户先导出加密备份，再直接覆盖安装；不要卸载旧版或清除数据。如果系统提示签名冲突，请保留旧版和数据，不要用卸载解决。

本版仍是 Alpha 测试版，GitHub Release 标记为 Pre-release。仓库默认私有，需要登录具有访问权限的 GitHub 账号。

## 这版有什么变化

- 首页先展示今日营养和热量，方案配置放在其后。
- 饮食入口更紧凑，相册与手工记录在大字体或窄屏下自动纵排。
- 每餐突出本次食物、克重、热量和三大营养素，参考来源与每 100 g 数值可展开。
- 深色卡片层次更清楚，训练历史的返回按钮固定在顶部。

本轮不修改数据库结构、模型请求协议或确认入账规则，不重新计算已有餐食。

## 隐私和使用边界

照片营养是可修改的估算，须本人核对确认才入账；照片识别会向所选外部服务发送图片及附加提示词。米饭已知重量可以作为参照，但不能消除隐藏用油、配方或遮挡带来的误差。

小米同步是可选的非官方云端通路，不直接连接 S400；账号、地区或服务变化可能造成不可用。体脂率和体水分取原返回值，缺失留空。

本版没有新增早午晚餐分类或已确认照片留存；“入账时间”不等于真实进餐时间。完整使用流程见 [README](../README.md)。
